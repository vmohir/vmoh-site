# sixes

Sixes — a pass-and-play roll-and-write dice game following the real turn
structure and per-color rules of _That's Pretty Clever_ (Ganz Schön Clever):
white wild die, 3-roll pick-and-shrink turns, the Silver Platter, and five
differently-ruled colored columns. 1-6 players, one device. See `CLAUDE.md` for
exactly what's faithful vs. approximated.

```
pnpm install
pnpm dev          # http://localhost:4321
pnpm build        # static build → dist/
pnpm preview
```

See `CLAUDE.md` for architecture and conventions.
