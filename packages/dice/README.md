# sixes

Sixes — a pass-and-play roll-and-write dice game, in the spirit of games like
_That's Pretty Clever_. 1-6 players, one device.

```
pnpm install
pnpm dev          # http://localhost:4321
pnpm build        # static build → dist/
pnpm preview
```

See `CLAUDE.md` for architecture and conventions.
